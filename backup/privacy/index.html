Privacy policy

Effective: 28 November 2026

This policy describes Portfolio Backup, a private utility for the authorized administrator of gulcan.net.

Data accessed and purpose

The application requests the Google Drive drive.file OAuth scope to create, read, verify and manage its own backup files and files explicitly authorized for its use. It is not intended to access unrelated personal Drive files. The planned backups contain website source code, Git history, project images, the portfolio PDF and separately supplied non-secret restoration files. The utility does not intentionally collect website visitors’ personal information, mailbox contents or live contact-form submissions.

Storage, processing and retention

GitHub Actions processes backup archives and Google Drive stores them for the authorized administrator. OAuth credentials are intended to be stored in GitHub repository secrets, not in public website files or backup archives. The retention policy is to keep the three newest verified backups and remove older backups after verification; Google Drive trash and provider retention settings may affect final deletion.

Use and disclosure

Google user data is used only to provide and maintain the backup and recovery function. It is not sold, used for advertising or transferred for unrelated purposes. Data is processed by GitHub and Google as necessary to operate the service. Portfolio Backup’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements where applicable.

Control and deletion

The administrator may revoke authorization through Google Account connections, disable the GitHub workflow, remove its credentials and delete backup files from Google Drive. For privacy questions or deletion requests, use the website contact form.
