Portfolio Backup

Portfolio Backup is a private, owner-operated utility for backing up the source repository and website assets of gulcan.net. It is intended for the authorized site administrator, not for public registration or use.

The planned workflow uses GitHub Actions to create and verify backup archives and store them in a designated Google Drive backup folder. It requests the limited Google Drive drive.file permission to manage files created or explicitly authorized for the application. The retention policy is the three most recent verified backups.

For questions, use the website contact form.
